# Python Library Demo

Навчальний проєкт для демонстрації 10 сторонніх бібліотек і 5 вбудованих модулів Python.

## Запуск

1. Створіть і активуйте віртуальне середовище.
2. Встановіть залежності: `python -m pip install -r requirements.txt`
3. Запустіть: `python main.py`

У проєкті 16 Python-файлів: `main.py` і 15 файлів із окремими функціями. `requirements.txt` та `README.md` — допоміжні файли.
Графік, зображення й QR-код створюються в поточній папці під час запуску.
